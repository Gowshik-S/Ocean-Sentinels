1. PROJECT OVERVIEW
================================================================================

Ocean Sentinels is a comprehensive coastal safety and hazard reporting platform
designed for coastal communities worldwide. It provides real-time maritime
incident reporting, response coordination, and offline mesh networking
capabilities for areas with limited connectivity.

MISSION: Keep coastal communities connected when internet infrastructure
         fails during maritime disasters.

PLATFORMS:
  • Web (Vanilla JavaScript ES6+) - COMPLETE
  • Android (Kotlin/Compose) - IN PROGRESS
  • iOS (Swift/SwiftUI) - IN PROGRESS

CORE PURPOSE:
  Real-time incident reporting with GPS/photos, live mapping, role-based
  dashboards, offline BLE mesh networking, weather integration, and
  multi-platform support.

3. TECHNOLOGY STACK
================================================================================

BACKEND:
  Language: Python 3.11+
  Framework: FastAPI (async/await)
  ORM: SQLAlchemy 2.0
  Database: PostgreSQL (primary), SQLite (local dev)
  Cache: Redis
  Auth: JWT (PyJWT), bcrypt password hashing

  Language: Vanilla JavaScript (ES6+)
  Mapping: Mapbox GL JS
  Styling: CSS3 (responsive)
  Charts: Trend analysis (in-house)
  Architecture: MVC-inspired, role-based modules
  Deployment: Vercel or Netlify

ANDROID:
  Language: Kotlin 1.9+
  UI: Jetpack Compose
  Architecture: Clean Architecture + MVVM
  DI: Hilt
  Database: Room
  Networking: Retrofit + OkHttp
  Maps: Mapbox Maps SDK for Android
  Messaging: Firebase Cloud Messaging (FCM)
  Bluetooth: Custom BLE mesh (Coded PHY / 1M)
  Build: Gradle 8.0+

iOS:
  Language: Swift (in progress)
  UI: SwiftUI
  Architecture: MVVM
  Networking: URLSession/Combine
  Maps: MapKit
  Messaging: Apple Push Notification service (APNs)
  Bluetooth: CoreBluetooth
  Build: Xcode build system

5. DATABASE SCHEMA (SIMPLIFIED)
================================================================================

USERS TABLE:
  - id (primary key)
  - username (unique)
  - email (unique)
  - hashed_password
  - first_name, last_name
  - phone, location
  - role (ENUM: public, admin, authority, rescue_team)
  - is_active, is_verified
  - created_at, updated_at, last_login (timestamps)

INCIDENTS TABLE:
  - id (primary key)
  - reference_id (unique)
  - hazard_type (ENUM: HIGH_WAVES, STRONG_CURRENTS, FLOODING, TSUNAMI, 
                       LOST_VESSEL, DEBRIS, EROSION, STORM, OIL_SPILL, OTHER)
  - location
  - latitude, longitude
  - description
  - urgency (ENUM: LOW, MEDIUM, HIGH, CRITICAL)
  - status (ENUM: PENDING, VERIFIED, IN_PROGRESS, RESOLVED, FALSE_ALARM)
  - contact_info, photo_url
  - mesh_message_id (for BLE mesh deduplication, unique)
  - reporter_id (FK to users)
  - verified_by_id (FK to users)
  - assigned_to_id (FK to users)
  - created_at, updated_at, verified_at, resolved_at, assigned_at (timestamps)

ANALYTICS TABLE:
  - Aggregated metrics for dashboard performance

15. COMMON ISSUES & TROUBLESHOOTING
================================================================================

BACKEND WON'T START:
  ✓ Check DATABASE_URL set correctly
  ✓ Verify PostgreSQL running (psql -U user -h localhost)
  ✓ Check SECRET_KEY not empty
  ✓ View error logs: check terminal output

FRONTEND NOT LOADING:
  ✓ Check frontend server running (python start_frontend.py)
  ✓ Verify http://localhost:3000 accessible
  ✓ Clear browser cache (Ctrl+Shift+Delete)
  ✓ Check browser console for errors (F12)

MAPBOX NOT RENDERING:
  ✓ Verify MAPBOX_TOKEN set in .env
  ✓ Check token is public token (not secret)
  ✓ Verify browser supports WebGL
  ✓ Check network tab for CSS/JS loading

API RETURNS 401 UNAUTHORIZED:
  ✓ Check JWT token in localStorage (DevTools > Storage)
  ✓ Verify token not expired (exp field in JWT)
  ✓ Check Authorization header format: "Bearer {token}"
  ✓ Try logging out and back in

DATABASE MIGRATIONS FAIL:
  ✓ Run backend/scripts/migrate_mesh_column.py manually
  ✓ Check database user has ALTER TABLE permissions
  ✓ Clear old connections: `SELECT pg_terminate_backend(...)`
