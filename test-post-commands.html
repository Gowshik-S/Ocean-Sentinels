🌊 Ocean Hazard POST Commands Test Interface

This page demonstrates all available POST endpoints in the Ocean Hazard API.

🔑 Current Tokens

Admin Token:
User Token:

1. POST /api/auth/login (Form Data)

Purpose: Login with form data (username/password as form fields)

2. POST /api/auth/login-json (JSON Data)

Purpose: Login with JSON data

3. POST /api/auth/register (JSON Registration)

Purpose: Register new user with JSON data

4. POST /api/incidents/ (Create Incident)

Purpose: Create new incident report (Requires user token)

5. POST /api/admin/teams/ (Add Rescue Team - Admin Only)

Purpose: Add new rescue team (Requires admin token)

6. POST /api/admin/authorities/ (Add Authority - Admin Only)

Purpose: Add new authority (Requires admin token)
