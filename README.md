## 🚀 Features

### 🗺️ Live Interactive Map
- **Mapbox Integration**: Real-time interactive map with geolocation
- **Location Detection**: Automatically centers on user's location
- **50km Monitoring Radius**: Visual representation of monitoring area
- **Government UI**: Clean, professional interface design

### 📊 Analytics Dashboard
- Real-time hazard tracking
- Statistical reports and visualizations
- Performance metrics and KPIs

### 🔔 Alert System
- Live emergency notifications
- Location-based alert filtering
- Multi-channel alert distribution

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Mapping**: Mapbox GL JS v2.15.0
- **Icons**: Font Awesome 6.0.0
- **Responsive Design**: Mobile-first approach
- **Geolocation**: HTML5 Geolocation API

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Gowshik-S/Ocean-Hazard.git
   cd Ocean-Hazard
   ```

2. **Open in browser**
   - Navigate to `pages/index.html`
   - Or use a local server for better development experience

3. **For development**
   - Use VS Code with Live Server extension
   - Enable location services for full map functionality

## 📱 File Organization Benefits

### ✅ Professional Structure
- **Scalable**: Easy to add new files and features

### 📂 Directory Purposes
- **`assets/`**: All static resources (images, icons, fonts)
- **`docs/`**: Project documentation and specifications
- **`pages/`**: All HTML pages organized in one location
- **`scripts/`**: JavaScript functionality and logic
- **`styles/`**: All CSS files and stylesheets

## 🔧 Development Guidelines

### 📁 Adding New Files
- **Images**: Place in `assets/images/`
- **Icons**: Place in `assets/icons/`
- **Pages**: Place in `pages/` with proper path references
- **Scripts**: Place in `scripts/` with modular structure
- **Styles**: Place in `styles/` with descriptive names

### 🔗 Path References
All HTML files now use relative paths:
- CSS: `../styles/filename.css`
- JS: `../scripts/filename.js`
- Images: `../assets/images/filename.png`
